- **Họ và tên:** Tạ Quang Huy
- **Mã sinh viên:** B25DCCC083
- **Lớp:** INT1332-20261-18

---

## Hướng dẫn biên dịch và chạy chương trình

### Yêu cầu:
- Đã cài đặt Java Development Kit (JDK 8 trở lên, khuyên dùng JDK 17+).

### Biên dịch:
```bash
javac Main.java
```

### Chạy chương trình:
```bash
java Main
```
Sau đó nhập dữ liệu đầu vào từ bàn phím theo định dạng của đề bài.
